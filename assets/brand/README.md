# Marca — Surface Labs

**Surface Labs** é o nome do produto SaaS — uma **sub-marca do ecossistema Surface
Visual** (agência de visuais 3D do usuário), herdando a identidade visual.

## Logo
- **Símbolo (oficial do app): SPIROGRAPH** — curvas sobrepostas formando um triângulo
  arredondado com vazado central, em **gradiente azul→roxo→rosa**. Usar no cabeçalho do
  app e como ícone/favicon.
- Wordmark: **"SURFACE"** preto bold, caixa alta; **"LABS"** mais leve/itálico abaixo à
  direita; símbolo ®.
- Fundo branco (versão sobre fundo escuro a definir).
- ⚠️ NÃO confundir com o símbolo wireframe (vaso/torno): aquele é da **Surface Visual**
  (agência), NÃO deste produto.

**Salvar os arquivos da logo aqui** (substituir placeholders):
- `assets/brand/surface-labs-symbol.svg` (só o spirograph — favicon/app icon)
- `assets/brand/surface-labs-logo.svg` (spirograph + wordmark, horizontal)

## Paleta da marca (aprox. — extraída da logo, ajustar com os valores oficiais)
- Ciano:    `#29C2F2`
- Azul:     `#4B6CE0`
- Roxo:     `#8A3FD1`
- Magenta:  `#E5179A`
- Texto:    `#0D0D0D` (quase preto)
- Fundo:    `#FFFFFF`

Gradiente principal: ciano → roxo → magenta (linear).

## Direção da UI (decidida jun/2026)
- **Base branca** (UI clara, limpa, bastante respiro).
- **Detalhes em preto** — menus / sidebar / barras e elementos de UI podem ser escuros
  (preto quase puro, como nos mockups da marca).
- **Gradiente azul→roxo→rosa apenas como ACENTO** — destaques, botões primários,
  gráficos, estados ativos, toques de marca. Nunca dominando a tela.
- Substitui a antiga paleta teal/verde dos protótipos. Atualizar
  `PROMPT_REFACAO_TELAS.md` (seção de cores) para esta direção.
